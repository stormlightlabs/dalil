Dalil is a local repository guide for coding agents, usable by people through the same commands. It answers from the repository's Git history first, and from code search and the symbol graph second.

[ROADMAP.md](../../../ROADMAP.md) holds the decisions. This spec's Roadmap plan holds the open work.
