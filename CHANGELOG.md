# Changelog

## [Unreleased]

### 2026-08-15

#### Added

- Added task-personalized PageRank using explicit ranking seeds.
- Added a packaged Dalil skill and typed lifecycle dispatch for native hosts.
- Added the `dalil-mcp` stdio adapter over the shared analysis operations.
- Added the `dalil-core` crate as an embeddable API for orientation, mapping,
  context, impact, search, explanation, cache, and capability requests.
- Added repository-index relationship reuse for unchanged source records.
- Added `search` for bounded path, symbol, and concept anchors.
- Added `orient` as the typed, concise form of the default repository briefing.
- Added `impact` for bounded change evidence around local revisions and dirty
  worktrees.
- Added safe local change resolution and changed-symbol evidence to context
  requests.
- Added optional source-grounded teaching steps to context bundles.
- Added `context` for task-shaped files, symbols, relationships, tests, history,
  uncertainty, and next reads under one budget.
- Added next-read guidance to `explain`.

#### Changed

- Reorganized the workspace into separate CLI, core, and MCP crates while
  preserving `cargo install dalil` as the CLI package.
- Documented the primary CLI workflows and their shared evidence semantics.

### 2026-08-14

#### Added

- Added task-aware source-map ranking from task text, symbols, paths, languages,
  project roots, changed targets, and search terms.
- Added strong-file selection so bounded maps prefer useful structural or
  task evidence over weak filler.
- Added the documentation site, guides, integration references, and project
  metadata for Dalil.

#### Changed

- Renamed the project and command to Dalil.
