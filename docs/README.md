# Dalil documentation site

The Dalil documentation site is a static SvelteKit application.

## Develop

From this directory:

```sh
pnpm install
pnpm dev
```

## Check and build

```sh
pnpm check
pnpm lint
pnpm test
pnpm build
```

`pnpm build` generates the static site and its Pagefind search index in
`build/`.
